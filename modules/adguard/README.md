# AdGuard Home 一键部署包

把全网设备去广告这件事，变成「运行一个脚本 + 点完一个向导」。

---

## 这是什么

AdGuard Home 是一款开源的网络级广告与跟踪拦截工具。它运行在你自己的服务器上，充当一个「会过滤的 DNS 服务器」：

- 家里或手机上所有设备的域名解析先经过它，命中广告 / 跟踪 / 恶意域名的请求直接被拦下；
- 广告在「加载之前」就被拦掉，所以网页、App 里的大部分横幅和弹窗广告都会消失，页面打开还更快；
- 带有网页管理台：能看拦截统计、查询日志，可以一键暂停、自定义规则、给孩子设备单独设过滤策略；
- 数据全部在你自己的服务器上，不经过任何第三方。

本部署包包含两个脚本：

| 文件 | 作用 |
| --- | --- |
| `install.sh` | 一键安装（调用 AdGuard Home 官方安装脚本），自动注册为系统服务、开机自启；重复运行不会报错 |
| `uninstall.sh` | 干净卸载：停服务、删程序目录，并提示可能的残留数据位置 |

---

## 适用系统

- Ubuntu（20.04 / 22.04 / 24.04 等主流版本）
- Debian（11 / 12）
- 需要 systemd（上述系统默认都是）
- 架构不限：x86_64 和 ARM 都可以（官方安装脚本会自动识别）

---

## 准备工作

1. **一台海外 VPS**（云服务器）
   - 最低配置即可：1 核 CPU、512MB 内存、1GB 硬盘完全够用；
   - 需要有公网 IP，并能用 root 或 sudo 权限登录；
   - 系统装上面列出的 Ubuntu / Debian。
2. **放行端口**（在云厂商控制台的「安全组 / 防火墙」里设置）
   - **53 端口（TCP + UDP）必须放行**：这是 DNS 服务的端口，所有设备的解析请求都走它。放行后，任何人都能把你的服务器当公共 DNS 使用，建议同时在管理台里开启「访问设置」中的速率限制，或用防火墙只放行你自己的常用网络；
   - **3000 端口（TCP）需要放行**：首次设置向导和管理台使用。出于安全考虑，完成设置后可以考虑只放行你自己的 IP 访问 3000。
3. **一个能上网的终端**：用 SSH 登录你的服务器（Windows 可用系统自带的 PowerShell / 终端，Mac 可用「终端」App）。

## 三步使用法

### 第一步：上传

把本部署包的 `install.sh` 上传到你的服务器，例如用 scp 命令（在你自己电脑上执行）：

```bash
scp install.sh root@<你的服务器IP>:/root/
```

也可以直接在服务器上用文本编辑器新建文件、把脚本内容粘贴进去，效果一样。

### 第二步：运行

SSH 登录服务器后执行：

```bash
sudo bash install.sh
```

脚本会自动完成：权限与系统检查 → 下载并执行官方安装脚本 → 注册系统服务 → 打印访问地址。看到「安装完成」字样就说明这一步结束了。脚本可以重复运行：已经装好时它只会检查并汇报服务状态。

### 第三步：打开管理台完成向导

1. 在浏览器打开：`http://<你的服务器IP>:3000`
2. 进入首次设置向导后：
   - 管理员界面端口保持 **3000**，DNS 服务器端口保持 **53**；
   - 设置管理员用户名和一个强密码（务必记好，后续登录管理台要用）；
3. 向导完成后，把你的设备 DNS 改为 `<你的服务器IP>`：
   - 最省事的做法：在路由器的 DHCP / DNS 设置里填这台服务器的地址，全家设备自动生效；
   - 也可以只改单个设备：手机 / 电脑的网络设置里把 DNS 改为该地址。
4. 回到管理台首页，能看到查询数和拦截数开始增长，就说明已经在工作了。

卸载时运行 `sudo bash uninstall.sh`，并记得把设备 / 路由器上的 DNS 改回原来的设置。

## 推荐设置

完成向导后，花两分钟按下面调一下，效果会明显更好。

### 1. 上游 DNS 用 Quad9（DoH 加密）

管理台 → 设置 → DNS 设置 → 上游 DNS 服务器，填入 Quad9 的 DoH 地址：

```
https://dns.quad9.net/dns-query
```

Quad9 是知名的非营利公共 DNS，本身就带恶意域名拦截；用 DoH 加密方式查询，还能避免解析请求在传输途中被窥探或篡改。同页的「引导 DNS 服务器」可填你熟悉的公共 DNS（如运营商默认或云厂商内网 DNS），格式保持普通 IP 即可。

### 2. 过滤规则：用管理台内置清单

管理台 → 过滤器 → DNS 封锁清单 → 添加封锁清单 → **从列表中选择**。管理台内置了一批官方与社区维护的知名清单，勾选即可自动更新，不需要自己去找订阅链接。推荐组合：

| 清单名称 | 说明 |
| --- | --- |
| AdGuard DNS filter | 官方维护的基础清单，必选 |
| AdAway Default Blocklist | 老牌移动端广告拦截清单，补漏效果好 |
| OISD Blocklist | 社区知名综合清单，误杀率低，适合长期开 |
| 1Hosts (Lite) | 规模较大的综合清单，Lite 版兼顾效果与误杀 |
| Steven Black's Unified Hosts | 知名开源 hosts 合集，偏重广告与跟踪 |

建议先开前 3 个，用一两天没遇到误拦（正常网站打不开），再按需加后面的。清单越多误杀概率越高，贵精不贵多。

### 3. 其他小开关

- **设置 → 常规设置**：开启「自动更新」省心；查询日志保留时间按硬盘大小设 7–30 天；
- **设置 → DNS 设置**：开启「速率限制」可以防止你的服务器被别人拿去滥用；
- 某个网站被误拦时：到「查询日志」里找到被拦的域名，一键加入允许清单即可，不必关掉整个规则。

## 常见问题

**Q1：安装成功，但把设备 DNS 改过去后上不了网 / 拦截不生效？**
大概率是 53 端口被系统自带的 systemd-resolved 占了。先运行 `sudo ss -lntup | grep :53` 确认占用者；若是 systemd-resolved，可编辑 `/etc/systemd/resolved.conf`，把 `DNSStubListener` 一项设为 `no`（该行默认被注释，去掉 `#` 并改值），然后 `sudo systemctl restart systemd-resolved`，再 `sudo systemctl restart AdGuardHome`。操作前请确保你还有其他方式登录服务器。

**Q2：浏览器打不开 `http://<你的服务器IP>:3000`？**
按顺序排查：① 在服务器上运行 `systemctl status AdGuardHome`，确认服务是 active (running)；② 检查云厂商安全组是否放行了 3000/TCP；③ 确认地址里的 IP 是服务器的公网 IP，且 http 前缀没写成 https。

**Q3：忘了管理员密码怎么办？**
先停服务：`sudo systemctl stop AdGuardHome`，然后编辑 `/opt/AdGuardHome/AdGuardHome.yaml`，找到 `users:` 下的 `password:` 一行，用 `htpasswd -bnBC 10 "" '你的新密码'` 生成的哈希替换它（htpasswd 在 apache2-utils 包里，没有就先 `sudo apt install -y apache2-utils`），保存后 `sudo systemctl start AdGuardHome` 即可用新密码登录。实在搞不定，也可以删掉该 yaml 文件重启服务，重新走一遍向导（已有规则设置会丢失）。

**Q4：规则都开了，为什么某些 App 里还是有广告？**
AdGuard Home 工作在 DNS 层：广告和内容走同一个域名的 App 内广告（如部分视频 App 的贴片）没法靠 DNS 区分拦截；另外少数 App 会内置加密 DNS 绕过系统设置。查询日志能帮你判断某个广告请求到底有没有经过 AdGuard Home——没经过的，属于上述情况，属正常现象。

**Q5：怎么更新版本？重复运行安装脚本会丢数据吗？**
两种方式都可以：管理台右下角出现新版本提示时点「更新」；或者直接重跑 `sudo bash install.sh`，脚本检测到已安装后不会覆盖重装。你的配置和数据都在 `/opt/AdGuardHome` 目录内，日常更新不会丢失；重大操作前可先把整个目录打包备份一份。
